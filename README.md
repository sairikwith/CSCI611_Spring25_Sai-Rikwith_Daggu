# CSCI611 Assignment 2 - Image Filtering & CNN Implementation

## Overview
This repository contains the implementation of image filtering techniques and a Convolutional Neural Network (CNN) for **Assignment 2** of **CSCI611**.

## Project Breakdown

### 📌 Part 1: Image Filtering (30%)
- Implemented multiple image filtering techniques.
- Completed all required tasks in `image_filter.ipynb`.
- Features:
  - Image preprocessing.
  - Applying various filters.
  - Displaying and analyzing filtered results.

### 📌 Part 2: Convolutional Neural Network (60%)
- Designed and trained a CNN from scratch.
- Implemented all required tasks in `build_cnn.ipynb`.

  - Defining the network architecture.

## 💻 Setup & Execution

### Step 1: Clone the Repository
```bash
git clone https://github.com/sairikwith/CSCI611_Spring25_Sai-Rikwith_Daggu.git
cd CSCI611_Spring25_Sai-Rikwith_Daggu
git checkout Assignment_2
```

### Step 2: Set Up a Virtual Environment
It is recommended to use a virtual environment for package management.

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

Install the required dependencies:
```bash
pip install numpy tensorflow matplotlib jupyter opencv-python pandas
```

### Step 3: Running the Notebooks
1. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
2. **For Image Filtering:**
   - Open `image_filter.ipynb`.
   - Execute all cells in order.
   - Observe and analyze the visual results.

3. **For CNN Implementation:**
   - Open `build_cnn.ipynb`.
   - Run all cells sequentially.
   - Track training progress and accuracy.
